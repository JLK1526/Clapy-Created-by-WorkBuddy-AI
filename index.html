游戏规则

吸气每吸一口气，自己的气数 +1；被任意等级的攻击命中时，吸气视为 0 级防御，直接死亡。
防御x 级防御消耗 x−1 口气（1 级防御消耗 0 口气），防御力 = x，最高 4 级。
攻击y 级攻击消耗 y 口气，攻击力 = y，最高 5 级；5 级只有攻击，没有防御。
判定攻击力 大于 对方防御力（或对方攻击力）时，对方死亡，本场对战结束；同级攻击双方扣气后继续，不存在同归于尽。
操作二级菜单：先点「吸气 / 防御 / 攻击」，再点具体等级；点开一个分类时，其他分类的展开面板自动收起。
节奏回合间隔 0.3–0.5 秒；气数不足时按攻击会在下方提示「气数不足」，改按其他按钮提示消失。
